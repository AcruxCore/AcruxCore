# Pricing pages, read 2026-10-16 ~10:20 PKT (05:20 UTC)

## Langfuse — https://langfuse.com/pricing (Langfuse Cloud tab)

- Hobby: free. 50k units / month, 30 days data access, 2 users. Annotation queues: 1 queue.
  General API 30 req/min, Datasets API 100 req/min, ingestion 1,000 req/min. Alerts: 2.
- Core: $29 / month. 100k units included, additional $8/100k units (graduated: 100k–1M $8/100k,
  1–10M $7/100k, 10–50M $6.5/100k, 50M+ $6/100k). 90 days data access. Unlimited users.
  Annotation queues: 3. General API 100 req/min.
- Pro: $199 / month. Same unit pricing. 3 years data access, unlimited annotation queues,
  high rate limits. Teams add-on $300/mo (SSO, RBAC).
- Enterprise: $2,499 / month.
- Billable unit (FAQ): "any tracing data point you send to our platform — this includes the
  trace …, observations (… Spans, Events and Generations), and scores".
- Calculator example on the page: Core, 200,000 units → $29 + $8 = $37 / month.
- Data region: US, EU or JP on all cloud plans. Prompt fetching unlimited on all plans.

## LangSmith — https://www.langchain.com/pricing

- Developer: $0 / seat, max 1 seat. 5k base traces / mo included, then pay as you go.
- Plus: $39 / seat / month, unlimited seats. 10k base traces / mo included, then pay as you go.
  Calculator text: "$39 / seat / mo · includes 10K traces total · 0.005 LSU / additional trace".
  1 LSU = $1.00.
- Enterprise: custom; the only plan with self-hosted or hybrid hosting.
- Base traces: 14-day retention. Extended traces: 180-day retention, "for an additional fee"
  (rate not shown on the page).
- A trace "can include many individual steps"; billing is per trace, not per step.
- Annotation queue (human feedback), Prompt Hub and Playground, online and offline evals listed
  under Observability & Evaluation for all plans.
- Data location: LangChain's cloud, US or EU.

## Side by side: 100,000 traces a month, 3 people

| | LangSmith Plus | Langfuse Core |
|---|---|---|
| Monthly price | $567 (3 × $39 seats + 90,000 extra traces × $0.005) | $98.36 (no scores) to $119.69 (3 scores per trace) |
| What is billed | Traces; steps inside a trace are free | Every trace, observation and score |
| Retention | 14 days (base traces); 180 days costs extra | 90 days |
| Seats | $39 per seat | Unlimited users |

LangSmith's bill does not change with trace size. Langfuse's does: an app with 30 observations
per trace would use 3.1M units for the same 100k traces.
